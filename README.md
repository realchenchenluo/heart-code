# 爱心代码 · 两枚

两个纯静态的爱心动画网页，无依赖、无构建，打开就能跑。

| 页面 | 说明 |
| --- | --- |
| [index.html](./index.html) | 落地页，两张卡各带一个实时预览 |
| [popup.html](./popup.html) | **弹窗爱心**：近百个 Windows 弹窗沿心形曲线排成一圈 |
| [particle.html](./particle.html) | **粒子爱心**：数千颗粒子组成的 3D 真心 |

## 弹窗爱心

- 96 个窗口沿着心形曲线等弧长排布，窗口长边跟着曲线切线转向，一层压一层，拼出一颗心。
- 出场时每个窗口从心形外侧飞入、错峰落位；随后整颗心按「咚·咚」两拍的心跳缩放。
- 中间那扇窗口写着你输入的话，底部输入框可以直接改（回车生效）。
- 点击画面任意处 = 重新拼一次；鼠标悬停某个窗口会把它顶到最上层并轻微放大。

## 粒子爱心

- 粒子分三层：外表面（沿心形轮廓的壳）、内部云、外围星尘，组成一颗有厚度的 3D 心。
- 绕 Y 轴持续旋转，配合透视投影和按深度着色的明暗，近处亮白、远处暗红。
- 心跳同样走双拍曲线；鼠标划过粒子会被推开、松手后弹回，点击会炸开一圈冲击波。
- 右下控制栏可调：粒子数（1200–9000）、转速（0–1.2 rad/s）、主题色（粉 / 彩虹 / 冰蓝 / 鎏金）、心跳开关、中间的文字。

## 本地运行

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

直接双击 `index.html` 也能用（没有用到任何模块加载，不受 `file://` 限制）。

## 两个小参数

- 任意页面加 `?preview=1` 进入预览模式：隐藏控制栏、降低粒子数、关掉鼠标交互 —— 落地页的卡片预览就是这么嵌的。
- 文字默认「万事胜意」，页面里直接改就行；弹窗爱心还有个 `--c` 配色在 `popup.html` 的 `PALETTE` 数组里。

## 关于这条曲线的两个坑

心形参数方程 `x = 16sin³t, y = 13cos t − 5cos2t − 2cos3t − cos4t` 在 `t=0`（顶部凹陷）和 `t=π`（底部心尖）处是**尖点**，`x` 是 `t` 的三次方：

1. **按 t 均匀采样会把点堆在一起** —— 尖点附近一大段 t 都挤在 `x≈0` 上。弹窗版本表现为一堆窗口糊成一坨，粒子版本表现为正中间一条竖直亮线。两个页面都改成先建弧长表、再按弧长等距取点。
2. **尖点处切线会翻转** —— 窗口正好落在尖点上会横竖打架。做法是跳过尖点附近一个步长的窗口，并让越靠近尖点的窗口缩得越小，像丝带在急转弯处收窄。

- [dddddd1/loveMove](https://github.com/dddddd1/loveMove) — 带在线演示的爱心代码
