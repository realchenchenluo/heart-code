# 爱心代码 · 两枚

两个纯静态的爱心动画网页，无依赖、无构建，打开就能跑。

| 页面 | 说明 |
| --- | --- |
| [index.html](./index.html) | 落地页，两张卡各带一个实时预览 |
| [popup.html](./popup.html) | **弹窗爱心**：近百个 Windows 弹窗沿心形曲线排成一圈 |
| [particle.html](./particle.html) | **粒子爱心**：数千颗粒子组成的 3D 真心 |

## 弹窗爱心

四个阶段自动循环，也可以手动干预：

1. **贴** — 窗口沿着心形曲线一个一个贴上去。每扇都从上一个窗口的位置顺着切线滑到自己的位置，露在外面的那一侧正好是刚贴上的新窗口，看着就是一支笔在画心。
2. **跳** — 贴完按「咚·咚」两拍心跳缩放。
3. **炸开** — 所有窗口飞散开、铺满整个屏幕（心形的 74 扇 + 只为散开准备的 78 扇），每扇都写着一句夸你的话。
4. **收心** — 再一起飞回心形，回到第 2 步。

底部「散开」按钮可以立刻切到炸开/收回，不用等循环。

其它：

- 窗口分两圈铺出有厚度的带子。每圈按「间距 ≈ 0.55 个窗口宽」定数量——重叠太多的话每扇只剩一条缝，写在上面的字就全被压住了。
- **每扇窗口都写着一句夸你的话**，文字左对齐，正好落在露出来的那一条里。中间那扇主窗口可以单独改。
- 配色是高饱和的荧光色（品红 / 青 / 黄 / 橙 / 绿 / 紫 / 蓝 / 青绿），配深色文字。
- 点底部「语录」按钮能编辑整个语录本（一行一句），改完立刻生效。
- 点击画面任意处 = 重新贴一次。

## 粒子爱心

- 粒子分三层：外表面（沿心形轮廓的壳）、内部云、外围星尘，组成一颗有厚度的 3D 心。
- 绕 Y 轴持续旋转，配合透视投影和按深度着色的明暗。
- 每颗粒子用一张预渲染的**辉光贴图**来画（中心一个亮点、外圈拖一条光晕尾巴），整颗心会自己发光，不是干巴巴的像素点。
- 心跳是**双拍**的：第一声重、第二声轻，之后一段平息。心跳那一下整颗心胀大约 9.5%，所有粒子同时被向外推一把，背景光晕跟着一起亮起来。
- 鼠标划过粒子会被推开、松手后弹回，点击会炸开一圈冲击波。
- 右下控制栏可调：粒子数（1200–9000）、转速（0–1.2 rad/s，调到 0 可以静止看心跳）、主题色（粉 / 彩虹 / 冰蓝 / 鎏金）、心跳开关。

## 本地运行

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

直接双击 `index.html` 也能用（没有用到任何模块加载，不受 `file://` 限制）。

## 两个小参数

- 任意页面加 `?preview=1` 进入预览模式：隐藏控制栏、降低粒子数、关掉鼠标交互 —— 落地页的卡片预览就是这么嵌的。
- 弹窗爱心的默认语录是 28 句，主窗口默认「你值得所有美好」，都在页面上改；窗口配色在 `popup.html` 的 `PALETTE` 数组里（每组是 浅色 / 深色 / 文字色）。

## 关于这条曲线的两个坑

心形参数方程 `x = 16sin³t, y = 13cos t − 5cos2t − 2cos3t − cos4t` 在 `t=0`（顶部凹陷）和 `t=π`（底部心尖）处是**尖点**，`x` 是 `t` 的三次方：

1. **按 t 均匀采样会把点堆在一起** —— 尖点附近一大段 t 都挤在 `x≈0` 上。弹窗版本表现为一堆窗口糊成一坨，粒子版本表现为正中间一条竖直亮线。两个页面都改成先建弧长表、再按弧长等距取点。
2. **尖点处切线会翻转** —— 窗口正好落在尖点上会横竖打架。做法是跳过尖点附近一个步长的窗口，并让越靠近尖点的窗口缩得越小，像丝带在急转弯处收窄。
